# Changelog

- Added immutable Meadows geode definitions, validated element weights and data-driven bonus yields/XP.
- Added weighted element selection and independent cracking bonuses; default slice remains Earth-only.
- Added workstation-gated shard recombination planning with configurable matching-shard cost.

- Bumped development definition schema to 2; all geode rules participate in the data hash. Persistent skill identity is unchanged.
- These are pure outcome planners; game inventory transactions, assets and multiplayer authority remain pending.
