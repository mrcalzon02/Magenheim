# Rift Titan concept-match outlook

Updated 2026-10-13 after the r10 layered/owned-surface pass. The user's current
rating is “not great.” Rift Titan is not adequately reworked and is not claimed
to have reached 85% concept fidelity. The adequate boss tally remains 1/6.

The planning estimate is **8–12 further substantial refinement passes after
r10** to aim for an 85% visual match. This is an uncertain work estimate, not a
measured similarity score or a guarantee. It assumes we keep the donor rig,
1,800-triangle soft cap and four 512px maps and make meaningful individualized
remodeling changes per pass rather than minor parameter adjustments. Repeated
visual regressions or native animation problems can extend the estimate.

| Directional stone fractures, chipped edge highlights, ochre/lichen placement, rib corrosion and violet emission | 2–3 | Same lighting as prior model, compact owned maps, close-up and gameplay-scale renders |
| Final coordinated corrections, conservative trimming and deformation/runtime review | 1–2 | Saved support/cap checks and native animation/performance evidence; user visual review |

For review, “85%” should mean that the dominant front/side silhouettes and
anatomical groupings agree, the important fractured stone/metal/crystal
features read correctly, and differences are mainly secondary chips and
surface nuances. A valid mesh or passing budget check is not concept matching.
No automated pixel score is used: the concept's perspective, pose and lighting
vary across views, and pixel overlap would reward incorrect interpretations.
The user's visual judgment remains the acceptance authority.

The r10 pass adds the preserved online crest's forward rake, broader supported
upper-thorax stones, longer overlapping limb plates, an irregular re-angled
core and an initial owned weathered surface atlas. The first material render
was too pale; palette/facet contrast was corrected against the source sheet.
This is still a first surface direction. Fine fragmentation and purposeful
weathering placement remain substantially unfinished.

Next pass: individually sculpt the head cleft and shoulder/arm contour chips,
using the source front and left-facing side rather than copying the current
model's large repeated wedges. Retain the torso rings, supported roots, donor
rig and performance envelope. Revisit this estimate after two further passes.
