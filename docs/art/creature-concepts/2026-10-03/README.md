# Magenheim creature design targets

48 of 48 individual sheets preserved. Built-in imagegen; prompts preserved in [prompts.json](prompts.json).

Adopted as the creature construction design reference on 3 October 2026.

[Open the filterable gallery](gallery.html) · [Construction and reference guide](../README.md)

Each sheet provides a concrete target for silhouette, anatomy and materials. Distill these into Valheim-scale geometry and owned textures using the construction guide; the artwork itself is not an installed model.
