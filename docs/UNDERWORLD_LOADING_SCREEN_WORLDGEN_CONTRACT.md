# Underworld loading-screen / worldgen contract

Status: binding art-direction and worldgen-fidelity contract.

The Underworld loading screens are not arbitrary promotional paintings. Their job is to show the
same world the player is about to enter, compressed into Valheim's restrained painted loading-art
language. A player does not need to find the exact same camera angle, but every dominant geographic
or structural idea in a loading image must have a real runtime path to exist.

## Fidelity rule

For every scene, separate the picture into four implementation layers:

1. **Heightfield geography** — basins, shores, ridges, cliffs, plateaus, spires and traversable
   slopes generated by the native Underworld terrain authority.
2. **Monumental landmarks** — free-standing roots, bridges, arches, pillars, ruin silhouettes,
   lavafalls and other shapes a heightfield cannot make.
3. **Ecology / structures** — biome vegetation, roads, settlements, ruins, resource fields and
   encounter locations.
4. **Atmosphere** — shared cavern roof presentation, fog, darkness, emissive light, weather and
   distance occlusion.
5. **Inhabitants** — at least one biome-appropriate creature, enemy or ambient life form whose
   silhouette is grounded in a runtime creature the player can actually encounter.

Artwork may combine those systems dramatically. It may not invent a fifth system that exists only
inside the PNG.

## Loading-art style invariant

The PNG is art only. Runtime supplies logos, tips, loading indicators and captions. Use broad
painterly forms, heavily drained charcoal/blue-grey colour, strong value silhouettes, organic fade
to black around the vignette and at least one dark Viking silhouette where composition allows.
Avoid microtexture prompting such as "ultra detailed" or "high detail"; that language produces
wrinkled/crinkled surface noise and is contrary to the target. The Viking remains the viewer-scale
anchor; biome inhabitants should read as stalking shapes, distant fliers, shoreline forms,
foreground threats or ambient silhouettes rather than isolated character-sheet poses.

Creature fidelity follows the same promise rule as terrain fidelity. If runtime still presents a
creature as a donor prototype, the final painting must not quietly substitute a substantially
different finished monster. Advance the creature art/runtime binding or simplify the vignette.

## Worldroot Span implementation

`BlackwaterWorldrootSpanLandmarkFamily` reuses the checked-in
`underworld-flora-blackwater-drowned-root-arch` authored model and promotes it to a sparse
world-scale navigation landmark. The model is reused rather than replaced with a dense bespoke
mega-mesh: scale supplies the silhouette; the existing landmark reservation/arbitration system
supplies deterministic spacing and multiplayer-safe residency.

It is registered through the same native Valheim location path as the Split Pillar, Frozen Wall,
three lavafalls and Broken Ancient Bridge. This is intentionally not a second worldgen system.

## Acceptance

A scene becomes fidelity-accepted only after an in-game screenshot demonstrates the dominant
ingredients together under ordinary play conditions. Source presence is not visual acceptance.
Diagnostic Blender renders do not count. Until live proof exists, loading artwork should be treated
as provisional and kept inside the implemented envelope.

When art and world disagree, resolve the mismatch in this order:

1. If the feature is desirable and technically compatible, advance worldgen/landmarks toward it.
2. If the feature would require fragile or contradictory architecture, reduce the artwork.
3. If both can move, meet in the middle: simplify the artwork while adding the highest-value
   landmark/geography needed to make the scene genuinely discoverable.
