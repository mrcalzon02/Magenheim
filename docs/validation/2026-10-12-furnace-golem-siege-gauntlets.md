# Furnace Golem siege-gauntlet impact silhouette — 2026-10-12

Scope: existing Sulfurous Wastes Furnace Golem elite only. This is a targeted source-authoring refinement of its two principal melee weapons, not a new creature or a runtime acceptance.

The original model used two generic fist boxes (later chamfered plate volumes) and six 12-sided cone spikes. The replacement keeps the original FG_Fist_L/R and FG_FistSpike_L/R_1..3 object names, iron/slag material identities and Lower_L/R rigid rig bindings. Each gauntlet is a broad, angular hammer head with a projecting strike brow, a narrower wrist root, and a solid impact face. Each of its three forward-facing tines has a thick root and a downturned hooked tip. The tines penetrate the striking face slightly so there is no visual floating attachment.

The Blender-independent geometry source is tools/furnace_golem_siege_geometry.py. Each fist has 252 triangulated faces, each tooth 144; the eight affected objects contain 1,368 source triangles in total. These replace approximately 272 triangles of prior procedural fist/spike geometry, a net increase of approximately 1,096. The whole-model source count is not measured. The previous estimated regenerated source count was about 3,356 after the open-vent pass, so about 4,452 is a projection, NOT a measured Blender result. The checked-in shipping runtime binary/catalog still records 984 triangles and four materials; it was not regenerated here.

Six Blender-free tests cover manifold closure, positive winding/volume, per-face UVs, broadened forward hammer silhouette, forward/downward tooth curvature, component triangle counts and invalid dimensions. The procedural front/side/top QA image is untextured and does not establish approval against the user's original concept sheet. The approved illustration could not be recovered from the available repo, Drive and file-library searches; only the existing source anatomy and written design were used.

Performance/acceptance: Elite runtime LOD0 target is 14,000–24,000 triangles, LOD1 about 60–70%, LOD2 30–40%, and distant 12–20%. No optimized LOD or donor measurement was produced. Existing four material families remain unchanged; texture sizes and 2048px elite source maps remain unverified. Blender source regeneration, GLB/runtime parity, full-body silhouette and deformation against the approved concept, and in-Valheim performance remain open. Do not claim this geometry is present in the shipped binary.
