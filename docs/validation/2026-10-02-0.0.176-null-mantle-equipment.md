# 0.0.176 Null Mantle equipment gating

User reported character darkening without wearing the Null Mantle. Prior gating
searched inventory flags rather than native Humanoid.m_helmetItem. This allowed
inventory extension stale/cosmetic equip flags to activate presentation. Native
metadata confirms the protected helmet slot exists in the installed assembly.

New production equipment helper uses that actual local slot; remote players use
synchronized helmet identity only when their valid ZNetView is not locally owned.
LateUpdate independently checks current equipment before applying darkening/eyes.
Damage adaptation likewise requires actual current equipment. Unequip, disable,
destroy and failed presentation initialization restore cached property blocks and
clear presentation/adaptation state. Empty original indexed blocks are removed
with null, allowing current native renderer/body tint to show again. Materials,
meshes, skinning and donor appearance are not modified by this runtime effect.

Production-linked regression covers stale owned network state without a native
slot, actual Mantle, vanilla crown, unequip, remote Mantle and remote crown.
World-scope regression passed. Runtime compile zero warnings/errors. Installed
native gates are recorded with the final integrated checks in
`2026-10-03-0.0.176-underworld-presentation-terrain.md`.

Live confirmation remains pending: bare head and vanilla crown must remain normal;
equip/remove/re-equip Mantle and change other gear while equipped, then remove it.
The inventory-flag loophole is repaired, but the reported live symptom is not
claimed reproduced or resolved until this test.
