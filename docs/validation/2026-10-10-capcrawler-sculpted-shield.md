# Capcrawler physical carapace silhouette — 2026-10-10

**Scope:** Existing Fungal Forest Capcrawler only. Replaces the generic `Capcrawler_Carapace` subdivision-3 ico-sphere with a single sculpted, closed fungal shield. Preserves `CapcrawlerCarapace` material, original `(0,-0.015,0.31)` pivot, `Body` rigid rig assignment, the existing rim scutes, four dorsal shelf plates, three rear spore nodules, gills, legs, jaws, scale and behavior. No new creature anatomy or gameplay systems.

**Source repair:** `tools/capcrawler_carapace_geometry.py` generates 64-sector concentric dorsal folds, a shallow median keel, physically scalloped margins, an inset frontal notch, a downturned perimeter lip and a shallow underside arch. Three separate per-face UV islands prevent dorsal, ventral and rim texture regions from overlapping. `tools/author-underworld-capcrawler.py` calls the Blender adapter. `tools/verify-underworld-capcrawler.py` checks exact vertices, polygon winding, UV loops, rig and material to reject stale `.blend` source.

**Offline checks:** Six pure-Python tests pass for watertight manifold, outward orientation, positive signed volume, silhouette envelope, physical scallops, per-face UV areas, atlas separation and index integrity. The generated orthographic comparison shows the sculpted shield with the *existing* dorsal shelf/spore-nodule positions in context. This is not an approved concept-art comparison or a Blender render.

**Quality floor:** The prior cap was a 1,280-triangle ico-sphere. The new cap uses 2,816 triangles (64 sectors, 11 radial rings, top/bottom/rim). The source remains inside the previous 0.72 x 0.86 x 0.21 m envelope, maintaining low-crawler overhang. The established Seeker donor is still required as an *actual measured* lower bound: run `verify-underworld-capcrawler-donor-floor.py` against a fresh runtime donor export and compare both polygon count and source texture dimensions. The new geometry's triangle count alone does not establish that floor.
