# Biome ground features — 0.0.108

Ten new authored models extend the existing cover catalogue:

| Biome | Ground layer |
|---|---|
| Fungal Forest | Rootgrass carpet, taller tufts, low woven runners |
| Sulfurous Wastes | Crescent powder drift, wind ripples, raised lee bank |
| Blackwater Deep | Wet silt ripples on banks and submerged basin floors |
| Frozen Caverns | Frost needle fans |
| Fracture Zones | Faceted shale scree |
| Great Decay | Fibrous peat/root mats |

Source is editable Blender geometry with 512px baked authored atlases, GLB interchange files
and runtime mesh exports. Roots use dense tapered strands rather than a scaled tree root.
Sulfur is a closed smooth wind-shaped deposit, with a buried rim; it is not a tinted rock.
Ground cover stays walk-through, with no added colliders, lights, networking or item components.
Unity LODGroup culls these meshes below 3.5% screen height; ground patches do not cast shadows.
These are scenery, not harvestable resources or simulated moving/sinking powder.

## Placement

The existing ecology cell lifecycle and model cache remain the only runtime ownership paths.
A separately seeded 6x6 jittered grid proposes up to 36 low patches per 64m fungal cell; other
biomes use alternating slots (18). Existing canopy/rock seeds and positions are unchanged.
Ground features also participate in the existing understory palette. All proposals obey
biome, slope and water habitats and the 36m gate clearance. Surface normals orient broad
patches; two-metre footprint samples screen cliffs and sharply curved independent patches.
No changes are made to foreign or vanilla prefab assets.

## Verification

no collision or lights, and authored textures. The actual runtime importer checks that all
ten models are reachable through biome palettes and remain nonblocking. Full package checks
also cover UVs, winding, model hashes, generated freshness and existing content.
