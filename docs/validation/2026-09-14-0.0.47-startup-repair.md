# 0.0.47 startup repair

## Cause and repair

The active profile's 0.0.46 startup stopped in MagenheimPlugin.Awake with a Harmony
AmbiguousMatchException for ItemDrop.ItemData.GetDamage. Because patches install
before content registrars, this prevented skill and content initialization.

Inspection of installed assembly_valheim.dll established two GetDamage overloads
and two GetArmor overloads. Their parameterless wrappers call the (int, float)
calculation methods. Both socket patches now target those shared calculations
explicitly, once. The tooltip patch also targeted a nonexistent four-argument
signature; it now targets the installed six-argument method.

## Verification

- Core harness: 13,974 assertions passed.
- Runtime compilation: zero warnings/errors.
- New build gate resolves all 11 Harmony declarations and validates named argument
  bindings against installed game/runtime metadata. It rejects the old 0.0.46 DLL
  because GetDamage resolves ambiguously to two methods.
- Isolated Valheim startup with BepInEx 5.4.2350, Jotunn 2.30.0 and packaged 0.0.47:
  Loading [Magenheim 0.0.47], Registered Crystal Shaping, Magenheim 0.0.47 loaded
  definition schema 4, and Chainloader startup complete were observed. No Magenheim
  bootstrap error was recorded.
- Evidence: ignored dist/boot-fix-smoke-0.0.47/BepInEx/LogOutput.log and
  unity-patched.log. Doorstop 4 uses --doorstop-enabled and --doorstop-target-assembly;
  earlier command aliases/environment assumptions had not loaded the plugin.

## Limits

The standalone launch subsequently encountered Steam initialization errors. It
establishes plugin bootstrap, not world content registration, gameplay, skills-panel
rendering, multiplayer or persistence acceptance. The owned test process was stopped.
The full-profile log also contains an unrelated OreMines DLL restoration IOException
from Valheim1012CompatRestorer; this Magenheim patch does not repair that separate mod.

Next full-profile check: launch Modded, confirm version 0.0.47 and no Magenheim
registration errors, load a disposable character/world, open Skills, and exercise
socket damage/armor/tooltip calculations once per operation.
