## Deliberate admission boundary

No generated Rootwarren asset family is claimed from this execution. The valid repository state
therefore remains Planned with zero committed Rootwarren source/GLB/runtime payloads. The prepared
manual production forge is responsible for generating all 17 families, running model/source gates,
rendering the dedicated visual review plates, recording generated provenance/freshness and only then
promoting the Fungal dungeon catalog entry to RuntimeReady.

Partial asset families, early RuntimeReady promotion, a missing payload, missing Harmony harvest
persistence, or missing runtime room/location lifecycle are explicit production-contract failures.

## Live acceptance boundary

After a reviewed forged branch is reconciled/merged, TESTING.md requires fresh-world Fungal-only
placement, no Surface leakage, 32-48 major rooms, visible branching/loops, clean passage slopes and
seams, collidable cave shells, persistent creature clears, persistent one-shot resource harvests,
host/client agreement, save/reload, Fungal environment identity and exact return to the owning
Fungal Forest entrance. Source and Blender review alone do not establish live acceptance.
