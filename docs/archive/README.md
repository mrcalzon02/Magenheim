It is not the live implementation authority where it conflicts with `INSTRUCTIONS.md`, `PROJECT_STATE.md`, or `docs/MAGENHEIM_DESIGN_SPEC.md`.

Do not treat an archived feature description as evidence that its source, assets, runtime registration, networking, persistence, or validation exists.
